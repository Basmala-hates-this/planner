# React + Vite

This project is set up as a plain JavaScript React app using Vite.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Notes

- This version uses JavaScript files instead of TypeScript.
- The app entry points are in [src/main.jsx](src/main.jsx) and [src/App.jsx](src/App.jsx).
- ESLint is configured for JavaScript and JSX files in [eslint.config.js](eslint.config.js).
